# GenAI-For-Data-Engineers
Gen AI Guide For Data Domain- This guide is designed to help data professionals to understand and leverage Generative AI techniques within the data domain. This guide provides practical insights, workflows, and best practices tailored for real-world data scenarios.


What’s Inside
Overview of Generative AI: Key concepts, terminology, and the evolution of Gen AI in the data landscape.
Tokenization & Embeddings: Step-by-step labs and explanations on tokenization, word2vec, and embedding techniques.
Practical Notebooks: Hands-on Jupyter notebooks to experiment with tokenization, word2vec, and embeddings.
Transformers Architecture: Understand Encoder-Decoder model architecture
RAG and Vector Stores: Build a strong foundation with the modern AI databases.
